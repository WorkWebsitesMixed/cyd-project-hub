Suggested Build Order

A path from "just unboxed it" to advanced builds. Each stage adds one new skill, so nothing feels like a cliff. Everything up to Stage 5 needs no extra hardware.

The 10-minute confidence boost: if you just want to see your board light up today with zero coding, flash the ESP32 Marauder via its web flasher first. Then come back and do Stage 0 properly.
Stage 0 · Prove the board

Make sure the screen + touch work

Before any real project, flash a known-good demo so you know your toolchain and board are healthy.

You'll learn: Arduino IDE + ESP32 core setup, uploading, and the all-important TFT_eSPI User_Setup config.

Official CYD examples ↗ Pinout reference Touch calibration 15 min
Stage 1 · Your first real build

An internet display that does something you care about

A single, satisfying win. This is the project everyone remembers building first.

You'll learn: WiFi credentials, calling a web API, and drawing text + images to the screen.

🎧 Spotify DIY Thing — full walkthrough Beginner F1 Notifier Beginner GitHub Stats Beginner
Stage 2 · More no-hardware dashboards

Repeat the pattern, build fluency

Now that APIs click, knock out a few more. Each reinforces the same skills with new data.

You'll learn: JSON parsing, refresh loops, and laying out a nicer UI.

Aura Weather Beginner London Tube Arrivals Interm. System Monitor (Glances) Interm.
Stage 3 · Fun & toys

Play with graphics & touch

Lighter on networking, heavier on the fun. Great for showing people.

You'll learn: animation loops, the touch controller as input, and frame timing.

Pixel Aquarium Beginner Slots o' Fun Beginner Paintbox Beginner Fluid Simulation Interm.
Stage 4 · Smart home (still no extra HW)

Make it useful on your wall or desk

Turn the CYD into a control panel. ESPHome projects are YAML — a gentle on-ramp before deeper coding.

You'll learn: ESPHome/MQTT, talking to Home Assistant, and building touch control grids.

Home Assistant Monitor Interm. CYD-Klipper Beginner Stream Deck Interm. Sonos Remote Interm.
Stage 5 · Add your first sensor

Cross into hardware — one wire at a time

Your first project with a part beyond the board. Start with a 3-pin sensor before anything with motors/relays.

You'll learn: wiring to the CYD's free GPIO, reading a sensor, and graphing live data.

DHT11 Temp/Humidity 🔧 sensor Air-Quality Traffic Light 🔧 CO₂
Stage 6 · Advanced & retro

Emulators, controllers & deeper code

The big-swing builds — extra controllers, audio, or heavier firmware. You're ready now.

You'll learn: external inputs (Nunchuck/BLE), audio/DAC, SD streaming, and performance tuning.

Galagino arcade 🔧 Nunchuck T-HMI-C64 🔧 keyboard NerdMiner v2 Beginner* BAM Game Engine Advanced
Not a strict ladder. Skip around by interest — the only real prerequisite is Stage 0. If smart home is why you bought the board, jump to Stage 4; the ESPHome path barely needs coding. NerdMiner is marked Beginner* because it's a web-flash, even though mining sounds advanced.
