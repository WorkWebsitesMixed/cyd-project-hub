🎧 First-build walkthrough

Put Spotify "Now Playing" on your Cheap Yellow Display

The community's classic first CYD build — your currently-playing track, artist, and album art on a little desk screen. This is the full path from empty board to working display.

● Beginner ✅ No extra hardware ⏱ ~45–90 min (first time)
What you'll do
  1. Gather parts & accounts
  2. Install Arduino IDE + the ESP32 core
  3. Install the required libraries
  4. Point TFT_eSPI at the CYD (the #1 gotcha)
  5. Create a Spotify developer app
  6. Get your refresh token
  7. Fill in the config & upload
  8. Play a song 🎉
  9. Troubleshooting

Project repo: witnessmenow/Spotify-Diy-Thing ↗ — always cross-check its README for the exact current library versions.

Read this first: library and API details change over time. This guide gives you the full mental model and the CYD-specific settings; when a version number or exact filename differs, the repo's own README wins. Follow it alongside this page.

1Gather parts & accounts

  • A CYD (ESP32-2432S028R) — nothing else to buy.
  • A USB cable that carries data (not a charge-only cable). Micro-USB or USB-C depending on your board revision.
  • A Spotify account. Free works for showing the current track. (Playback control needs Premium, but this build just displays.)
  • Your 2.4 GHz WiFi name + password. The ESP32 does not do 5 GHz.
You'll need to be actively playing music on some device (phone, desktop app, web player) for anything to show — the CYD reads whatever your Spotify account is currently playing.

2Install Arduino IDE + the ESP32 core

  1. Install Arduino IDE 2.x.
  2. Open File → Preferences. In Additional boards manager URLs paste: 
    https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
  3. Tools → Board → Boards Manager → search esp32 → install "esp32 by Espressif Systems".
  4. Select the board: Tools → Board → ESP32 Arduino → "ESP32 Dev Module".
Board settings that work for the CYD:

3Install the required libraries

Use Tools → Manage Libraries (or Sketch → Include Library → Add .ZIP for GitHub-only ones). The Spotify-Diy-Thing project needs:

  • TFT_eSPI (by Bodmer) — the display driver.
  • ArduinoJson (by Benoît Blanchon) — parses the Spotify API responses.
  • spotify-api-arduino (by witnessmenow) — the Spotify client. Often installed from its GitHub repo as a ZIP.
  • TJpg_Decoder (by Bodmer) — decodes the JPEG album art.
The repo README lists the authoritative dependency set — install exactly what it names. If a compile fails on a missing .h, it's almost always one of these not installed.

4Point TFT_eSPI at the CYD (the #1 gotcha)

TFT_eSPI must be told which pins and driver the CYD uses, or you'll get a white/blank screen or wrong colors. Two ways:

Easiest: copy the official CYD setup file

Grab the ready-made User_Setup.h from the official ESP32-Cheap-Yellow-Display repo (see its SETUP.md) and replace the one inside your Arduino/libraries/TFT_eSPI/ folder.

Or set it manually — the CYD values are:

#define ILI9341_2_DRIVER     // note the "_2" — fixes the CYD's colors
#define TFT_WIDTH  240
#define TFT_HEIGHT 320

#define TFT_MISO 12
#define TFT_MOSI 13
#define TFT_SCLK 14
#define TFT_CS   15
#define TFT_DC    2
#define TFT_RST  -1          // tied to board reset
#define TFT_BL   21          // backlight
#define TFT_BACKLIGHT_ON HIGH

#define TOUCH_CS 33          // resistive touch (XPT2046)

#define SPI_FREQUENCY       55000000
#define SPI_TOUCH_FREQUENCY  2500000
Board revisions differ. Some CYDs use a different display controller or the plain ILI9341_DRIVER. If colors look inverted, switch between ILI9341_DRIVER and ILI9341_2_DRIVER, or add tft.invertDisplay(1). The official repo's SETUP.md documents each variant.

5Create a Spotify developer app

  1. Go to the Spotify Developer Dashboard and log in.
  2. Click Create app. Give it any name/description.
  3. For Redirect URI, add exactly what the project's token helper expects — commonly: 
    http://<YOUR-ESP-IP>/callback
    You'll learn the ESP's IP in step 6, then come back and set this precisely. It must match character-for-character.
  4. Save, then open Settings and copy your Client ID and Client Secret.

6Get your refresh token

Spotify needs a one-time authorization to hand your device a long-lived refresh token. The project includes a helper flow for this — the pattern is:

  1. Put your WiFi + Client ID + Client Secret into the config, and flash the sketch (or the included "get refresh token" example).
  2. Open Tools → Serial Monitor at 115200 baud. It prints the board's IP address once WiFi connects.
  3. Set your Spotify app's Redirect URI to http://<that-IP>/callback (step 5) if you haven't.
  4. Visit http://<that-IP>/ in a browser on the same network, click through the Spotify authorize prompt.
  5. The serial monitor (or page) shows your refresh token — copy it.
Follow the repo's exact instructions here — witnessmenow's Spotify libraries have a well-documented example for grabbing the refresh token, and the file/field names are in the README.

7Fill in the config & upload

Open the project's settings/secrets file and set:

WiFi SSID + password
Spotify Client ID
Spotify Client Secret
Spotify Refresh Token   // from step 6
(optional) market/country code, e.g. "US"
  1. Confirm your board settings from step 2 are still selected.
  2. Plug in the CYD, pick the right Port under Tools → Port.
  3. Click Upload (→). If it stalls at "Connecting…", hold the BOOT button while it starts, or lower upload speed to 115200.

8Play a song 🎉

Start playing anything in Spotify on your phone or computer. Within a few seconds the CYD should show the track, artist, and album art. That's it — you've built the classic CYD project.

Next tweaks: adjust polling interval, brightness via the backlight pin, or add the CYD's touch to skip/pause. Then head back to the hub and try the Spotify Visualizer for a fancier look.

9Troubleshooting

White or blank screen

Almost always the TFT_eSPI setup (step 4). Confirm you replaced/edited User_Setup.h in the actual TFT_eSPI library folder, and that the backlight pin (TFT_BL 21, ON = HIGH) is set. Re-upload after any change.

Colors look inverted or washed out

Toggle between ILI9341_DRIVER and ILI9341_2_DRIVER, or call tft.invertDisplay(1). Different CYD batches vary.

Won't connect to WiFi

The ESP32 is 2.4 GHz only. Check the SSID/password, and that it isn't a 5 GHz-only network. Special characters in the password can trip things up.

Spotify auth fails / "INVALID_CLIENT: Invalid redirect URI"

The Redirect URI in the Spotify dashboard must match the one the device uses exactly, including http://, the IP, and /callback. Update it if the board's IP changed (consider reserving a static IP in your router).

Nothing shows even though it's connected

You must be actively playing on your Spotify account. Paused/idle returns nothing. Also confirm the refresh token is pasted correctly with no stray spaces.

Upload fails at "Connecting…"

Use a data-capable USB cable, install CH340/CP210x USB-serial drivers if the port doesn't appear, hold BOOT during upload, and try upload speed 115200.
