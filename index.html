🔌 How to flash a CYD (quick start)

The CYD (ESP32-2432S028R) is a 2.8" ILI9341 resistive-touch board with an ESP32, microSD, RGB LED, light sensor and speaker output. Two main paths:

Path A — Web flasher (easiest, for prebuilt firmware)
  • ESP32 Marauder / HaleHound / NerdMiner: most ship a browser flasher — plug in via USB, open their flasher page in Chrome/Edge, click install. No toolchain needed.
  • If a repo has a Releases tab with .bin files, you can flash them at esptool-js or web.esphome.io.
Path B — Arduino IDE (for the DIY / games / dashboard projects)
  • Install Arduino IDE → add ESP32 boards URL in Preferences → Boards Manager → install "esp32 by Espressif".
  • Board: ESP32 Dev Module. Most CYD projects use the TFT_eSPI library — the repo usually includes a ready User_Setup.h (ILI9341, 240×320, correct pins). Copy it into the library folder.
  • Touch uses the XPT2046 resistive controller — many repos bundle XPT2046_Touchscreen or bb_captouch.
  • Set your WiFi SSID/password + any API keys in the sketch's config/secrets file, then Upload.
  • Best reference: the official ESP32-Cheap-Yellow-Display repo — pinouts, board variants (some ship the cheaper resistive vs newer capacitive touch), and troubleshooting.
Path C — ESPHome (for the Home Assistant / smart-home builds)
  • Smart-home projects (HA Monitor, SmartEnergyMeter, thermostat) are YAML configs flashed via ESPHome — install the ESPHome add-on in Home Assistant, paste the project YAML, and it compiles + flashes over USB or OTA.

⚠️ Heads-up: there are several CYD board revisions (different touch controllers, USB-C vs micro-USB, single/dual USB). Check which variant a project targets before flashing.
